Prilike za refaktoring — prioritet

1. HITNO — AgentLoop (eliminira ~130 LOC duplikata)
Definiši LLMBackend protokol. AnthropicBackend i PWRBackend implementiraju ga. AgentLoop.run(messages, backend) drži jednu while petlju. Preduslov za sve ostale refaktoringe.
2. Tool Registry (eliminira magic strings)
@tool_handler('category_overview') dekorator. dispatch() postaje lookup u registry. Novi tool = jedna funkcija, nema dodirivanja dispatch-a.
3. Budget/Cache Pipeline u run_suite()
Svaki entry prolazi kroz: BudgetGate → CacheGate → LLMCall → CachePut → BudgetRecord. Svaki stage je izolovan i testabilan.
4. Lazy tool data (eliminira module-level side effects)
CategoryRepository klasa sa load_on_first_access. Testovi mogu injectovati mock repozitorij bez monkeypatching.

Šta CM Scraper NEMA — prioritetni gaps

Tool Calling Nema structured tool_use. Modeli vraćaju slobodni JSON, post-hoc validacija — fragilno
Budget Gate Nema svjesnosti o trošku. Može neograničeno pozivati Opus bez kontrole
Eval Cache Svaki run zove API iznova. Nema SHA-256 keša za ponovljene upite
Resume Checkpoint = snapshot za inspekciju, NE za nastavak od pane faze
Vector Search PDF tekst ide direktno u prompt. Nema embeddinga ni retrieval-a
Mock seam call_model() se poziva direktno — nema seam-a za test mock

Plan implementacije

1. HITNO — ToolCallStage (structured output)
Novi stage između BuildPromptStage i FinalizeStage. Koristi Anthropic tool_use API umjesto slobodnog JSON-a. ctx.tool_results + ctx.tool_calls_log. Opcionalan via ctx.config.enable_tool_calling.
2. Context Object pattern — fix run_dir bug
Nije Memento, nije Strategy. Context Object (RunContext/EvalSession) nosi runtime stanje: start_index, completed_stages[], label, run_dir. Zna se serijalizovati i deserijalizovati. run_dir se seli iz SaveStage u PipelineContext constructor — dostupan svim fazama od starta.
3. Budget Gate (sliding window)
Port BitLab budget.py: 5h sliding window, per-provider tracker. Ide kao wrapper oko RunModelsStage ili kao middleware u Pipeline.run() — ne novi stage, nego pipeline-level concern.
4. Hibridna pretraga (low priority — future)
BM25 + cosine, MiniLM L6 v2 (384-dim), file-based (.npz + .json). Za pravne akte: embedovati odredbe umjesto cijelog dokumenta. Prirodna primjena: pronađi slične odredbe iz prethodnih zakona za kontekst.

BitLab hibridna pretraga — formula

fused = 0.6 * norm01(cosine_scores) + 0.4 * norm01(bm25_scores)
# Soft boost ako AI nije dao hard filter:
fused += 0.25 per matching category
fused += 0.25 per matching brand
# Max boost: +0.5 kumulativno
# Sort: (in_stock, -score_bucket, brand_priority, -score)
Embeddingsi se pre-normiraju pri upisivanju (normalize_embeddings=True) pa dot product direktno daje cosine — nema extra dijeljenja. Lazy model load (50s na WSL2, samo na prvom upitu).
